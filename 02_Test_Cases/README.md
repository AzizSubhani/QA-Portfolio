# 🧪 Test Cases

## Project

**ElderCare Connect**

## Purpose

This folder contains the manual test cases designed and executed for the ElderCare Connect web application.

The objective of these test cases is to validate that all major functionalities of the application work according to the specified requirements and provide a reliable user experience.

---

## Testing Approach

The test cases were designed using industry-standard test case writing practices and cover:

- Functional Testing
- Smoke Testing
- Regression Testing
- Integration Testing
- Boundary Value Analysis (BVA)
- Negative Testing
