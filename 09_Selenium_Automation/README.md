# 🤖 Selenium WebDriver Automation

## 📌 Overview

This folder contains a standalone **Selenium WebDriver automation project** created to demonstrate my UI automation and automated testing skills using Java.

The project is separate from the ElderCare Connect QA project and is intended to demonstrate practical knowledge of browser automation, test frameworks, and maintainable automation design.

---

## 🎯 Automation Objectives

The automation project demonstrates how to:

- Automate web application workflows
- Locate and interact with web elements
- Validate expected UI behavior
- Perform positive and negative testing
- Automate repetitive regression scenarios
- Organize tests using the Page Object Model
- Execute automated tests using TestNG
- Manage dependencies using Maven

---

| Technology | Purpose |

## 🧪 Automation Areas

The project focuses on common web application workflows such as:

- Login
- Invalid login
- Form validation
- Navigation
- Logout
- Basic functional UI verification
