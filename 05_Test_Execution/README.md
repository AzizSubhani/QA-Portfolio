## 📊 Test Status

The following statuses are used:

| Status | Meaning |
|---|---|
| **Passed** | Actual result matched the expected result. |
| **Failed** | Actual result did not match the expected result and a defect was identified. |
| **Blocked** | Test could not be completed because of an external dependency or blocking issue. |
