# 🗄️ ElderCare Connect — Database Testing

## 📌 Overview

This folder contains database testing documentation for the **ElderCare Connect** web application.

Database testing focuses on verifying that application data is correctly created, stored, updated, retrieved, and associated within the MongoDB database.

---

## 🎯 Testing Objectives

The main objectives of database testing are to:

- Verify data is stored correctly
- Validate CRUD operations
- Verify required fields
- Validate data consistency
- Verify relationships between application data
- Check role and user information
- Validate report data
- Verify Resident and Staff assignments
- Identify data synchronization issues

---

## 🛠 Database Technology

ElderCare Connect uses:

- **MongoDB** — Database
- **Mongoose** — Object Data Modeling (ODM)
- **MongoDB Compass** — Database inspection and validation
