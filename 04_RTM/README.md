# 📋 ElderCare Connect — Requirement Traceability Matrix

## 📌 Overview

This folder contains the **Requirement Traceability Matrix (RTM)** for the ElderCare Connect project.

The RTM establishes a relationship between the application's functional requirements and their corresponding test cases. It helps ensure that important requirements are covered by planned testing activities.

---

## 🎯 Purpose

The RTM is used to:

- Map requirements to test cases
- Verify test coverage
- Identify requirements without corresponding tests
- Maintain traceability between requirements and testing
- Support systematic QA documentation
