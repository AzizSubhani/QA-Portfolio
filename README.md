# 🧪 QA Portfolio

Welcome to my **Software Quality Assurance (SQA) Portfolio**.

This repository showcases my practical knowledge of **Manual Testing, API Testing, Database Testing, Test Documentation, and Selenium Automation** through real-world QA artifacts created while testing my Final Year Project, **ElderCare Connect**.

The goal of this portfolio is to demonstrate not only my understanding of software testing concepts but also my ability to apply them in a structured and professional manner.

---

# 👨‍💻 Project Under Test

## ElderCare Connect

**ElderCare Connect** is a MERN Stack web application developed as my Final Year Project.

The system connects **staff members**, **guardians**, **residents**, and **administrators** to manage elderly care efficiently.

As the **Team Lead**, I also contributed to Software Quality Assurance by planning testing activities, writing test cases, executing manual testing, validating APIs, reporting defects, and verifying fixes.
